2. Standar Operasional Prosedur (SOP) EHA

Cara Sanggah TJPH
  1. Tarik data suite TJPH, pindahkan ke sheet TJPH.
  2. Buat folder Google Drive berisi SS FMS & UNSLOG, CCTV inbound & outbound, izinkan akses ke email SPX/Shopee.
  3. Salin link Drive ke sheet TJPH, isi alasan sanggah sesuai status.
  4. Isi webform 3PL, lalu kirim email ke tim terkait.
Data Gantungan Hourly
  1. FMS -> Order Tracking -> Status SOC_RECEIVED, SOC_PACKED, SOC_PACKING, RETURN_*.
  2. Salin ID dan isi sheet Data Gantungan Hourly.
MCC FMHub_LHTransported
  1. FMS -> Order Tracking, status FMHub_LHTransported, salin ID.
  2. Isi sheet MCC, lalu kirim feedback email berisi screenshot pivot table & file MCC.
Proses NCR & RTS
  1. NCR: Isi sheet SJM, template Non-AWB, SPX Liquidation Form (Tujuan Jakarta Return DC).
  2. RTS: PDA -> Intra-Station Handover -> Create Task -> WS IHT Desentral Fixed_EHA -> EHA Outbound.
Proses Damage
  1. Foto & video inbound dan unboxing, info FM di grup SeaTalk.
  2. Buat berita & BA damage, email beserta foto/video (zip).
  3. Isi web damage handling, lalu EHA single inbound → eskalasi ke team claim.
  4. Tunggu sampai status berubah.
Proses Paket cancel
  1. Proses IHT in.
  2. FMS → Exception Handling Area, EHA Single Inbound & Resolve.
  3. EHA Inbound: scan ID, update status, print AWB.
  4. Catat di sheet EHA Reporting, lalu proses IHT outbound.
PROSES REPACKING
  1. PDA EXCEPTION HANDLING.
  2. EHA SINGLE INBOUND&RESOLVE.
  3. PILIH REASON 73 EHA_IN,OFFLINE RESOLVED.
  4. PILIH REASON 72 LAKBAN ULANG.
  5. WS IHT DESENTRAL FIXED_EHA,EHA OUTBOUND.
  6. COMPLETE.
  7. DATA DI SHEET EHA REPORTING,Sort Reguler / Raw Report EHA.
  8. Monitoring Tracert EHA TP SERANG 1.
PROSES RELABEL
  1. FMS,EXCEPTION HANDLING AREA,AWB PRINT,SPX Tracking Number:,SCAN AWB.
  2. CONFRIM,PRINT.
  3. WS IHT DESENTRAL FIXED_EHA,EHA OUTBOUND,SCAN AWB,COMPLETE.
  4. DATA DI SHEET EHA Reporting TP Serang,Sort Reguler / Raw Report EHA 1.
PROSES FEEDBACK EMAIL
